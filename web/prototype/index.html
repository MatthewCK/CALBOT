Five guesses, one winner

In March, the group chat put money on Cal's final home run total. Closest guess takes the pot. He'd hit 34 the year before, so the guesses clustered there, with one loud exception.

CALBOT watched every game and reran the odds after each one by simulating the rest of the season 20,000 times. Here's what it would have said at the point you've picked.

About the data. Real: Cal's monthly home run totals and milestone games (his first on March 31, 26 through 63 games, 38 at the All-Star break, 48 and 49 on August 24, 59 and 60 on September 24, 60 to finish). Approximate: the exact game each home run in between fell on, and the game dates, which are placed to match those checkpoints. The next version reads the real game log from the MLB Stats API.

About the bet. The names and guesses are stand-ins for the real group chat.

About the model. Cal's home run rate per game starts from his 2024 rate (34 in 153 games), weighted like 150 games of evidence, and updates with every game he plays. Each simulation draws a rate from that belief, then plays out the remaining games. Ties split the pot.
