Five guesses, one winner

In March, the group chat put money on Cal’s final home run total. Closest guess takes the pot. He’d hit 34 the year before, so the guesses clustered there, with one loud exception.

CALBOT watched every game and reran the odds after each one by simulating the rest of the season 20,000 times. Here’s what it would have said at the point you’ve picked.

About the data. Cal’s game log and the Mariners’ schedule come from the MLB Stats API. The charts count Mariners games, so the three games he sat out (marked on the season chart) are on the axis too; “his game” in the table counts only games he played. Every number on this page is read from the CALBOT model’s published outputs, and the page checks that they add up before drawing them.

About the bet. The names and guesses are stand-ins for the real group chat.

About the model. This is the “Lite” model. Cal’s home run rate per game starts from his previous season’s rate, weighted like 150 games of evidence, and updates with every game he plays. His share of games played gets the same treatment, starting from the year before. Each simulation draws a rate and a share from those beliefs, then plays out the games left. Ties split the pot.
