# CALBOT

A small family of projects about Cal Raleigh's home runs and a group-chat bet on his season total.

| Folder | What it is |
|---|---|
| `model/` | Python model: data, simulations, bet tracking, publishes outputs |
| `contract/` | The output format every consumer reads |
| `web/` | CALBOT Web, the interactive D3 site |
| `whatsapp/` | CALBOT WhatsApp, the Node bot (deployed on Railway) |
| `docs/` | The plan |

See `docs/PLAN.md` for the full plan.
